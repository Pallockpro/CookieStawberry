# CookieStawberry 🍓

Cookie Clicker page hosted with GitHub Pages. Made by Strawberries.

- **Autosave**: progress saves in your browser automatically (every 10/30/60s, your pick) and whenever you leave the page, with a backup copy.
- **💾 Saves**: save now (or press Ctrl+S), download a save file, or load one back in.
- **🤖 Auto Buy**: one switch to turn it on, then pick what it buys.
  - **Buildings**: tap tiles to choose which buildings get bought. Locked buildings show a 🔒 until you unlock them.
  - **Upgrades**: regular and cookie upgrades on/off; research (grandmapocalypse) is off by default. Toggle upgrades like Elder Pledge are never auto-bought.
  - **Extras**: auto-click golden cookies (optionally wrath cookies) and reindeer, buying strategy (best value / cheapest first), and a bank reserve so it never spends your Lucky combo cookies.
  - Shows what it's saving for next with a progress bar.
- **⚙ Performance**:
  - **⚡ iPad boost**: one tap turns on everything below that reduces lag.
  - **Fast mode**: turns off visual effects, shadows and filters.
  - **Mute click sounds**: biggest fix for lag while tapping the cookie on iPad.
  - **Hide building scenes**: hides and stops drawing the animated building rows (biggest saver).
  - **Smooth frame pacing**: runs the game loop on the screen's refresh instead of a jittery timer.
  - **Frame rate**: 30 fps (game default) or 60 fps (smoother, same game speed, more CPU).
  - **FPS counter**: green = hitting target, yellow/red = dropping frames.
- **Other**: autosave interval, hide the top link bar, show the credits popup again.
- **iPad**: pinch and double-tap zoom are blocked so the page never zooms by accident; *Share → Add to Home Screen* opens it full screen.
